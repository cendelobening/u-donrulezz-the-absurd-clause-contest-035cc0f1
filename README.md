One original English sentence, written as a clause buried deep inside a terms-of-service agreement: deadpan legal boilerplate that quietly turns absurd — the user's soul is treated like a defective product, returnable in substantially its original condition, less reasonable wear and tear, with the user footing the postage.

## The entry

> Upon termination, the user's soul shall be returned in substantially its original condition, less reasonable wear and tear, within thirty (30) business days of notice, postage prepaid by the user.

## How to run

```sh
python3 main.py
```

This writes the clause to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), creating the directory if needed and setting the output file mode to `0644`.
